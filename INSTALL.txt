Full installation guide (FR + EN) →  README.md

Quick start:
1. Create 3 Discord apps named exactly: Anime-Sama, YouTube, TikTok
   → https://discord.com/developers/applications
2. Put their Application IDs into bridge.py (replace the placeholders)
3. pip install -r requirements.txt
4. python bridge.py
5. chrome://extensions → Developer mode → Load unpacked (select this folder)
6. (Windows) Put start_bridge_background.pyw in shell:startup

See README.md for complete details, images, troubleshooting, etc.
